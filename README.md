## 🌟 Características

- **Hero con Nodos Elásticos Interactivos**: Simulación física en Canvas 2D Retina con resortes de Hooke y amortiguación elástica. Los nodos conectan los proyectos, herramientas y agentes del ecosistema.
- **Kit de Marca Oficial ApliArte**: Modo claro por defecto (`#fdfdfd`), modo oscuro canónico (`#303030`), azul primario (`#005fa9`) y cian acento (`#5ecef5`), con conmutador Sol / Luna persistente.
- **Factoría de Agentes Destacada**: Visor interactivo de prompts y enlace directo a la [Fábrica de Agentes de IA](https://erbolamm.github.io/FabricaDeAgentesApliarte/).
- **Escaparate de Software Libre**:
  - [**ApliArte AI**](https://github.com/erbolamm/apliarte-ai): Chat de IA 100% local para VS Code con transformers.js.
  - [**Key Master**](https://github.com/erbolamm/key-master): Entrenamiento de atajos de teclado para VS Code, Cursor y Windsurf.
  - [**Corrector Offline**](https://github.com/erbolamm/corrector-vscode): Corrección ortográfica para dislexia offline en VS Code.
  - [**TTS ApliArte**](https://github.com/erbolamm/tts-apliarte): Traducción y voz en tiempo real para directos de Twitch y YouTube.
  - [**Widget Canvas**](https://github.com/erbolamm/apliarte-widget-canvas): Lienzo visual interactivo para apps Flutter.
  - [**ClawMobil**](https://github.com/erbolamm/ClawMobil): Servidor de IA autónomo para Android con Telegram Bot y modelos offline.
  - [**SketchyBar Config**](https://github.com/erbolamm/SketchyBar-Config): Configurador visual para la barra de estado SketchyBar en macOS.
  - [**Zperiod (Traducción Oficial)**](https://zperiod.app/?lang=es): Tabla periódica 3D interactiva (Autor original: Philip Zhao / Zhilips; traducción y localización oficial al español por Javier Mateo).
- **Puente Fábrica ➔ Skills**: Integración arquitectónica para recargar dinámicamente las habilidades de agentes en Antigravity y Herdr.
